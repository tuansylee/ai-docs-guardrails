# API Reference

Beacon exposes three endpoints. See [Getting Started](getting-started.md) to install the client.

## Endpoints

| Endpoint | Requests | Errors |
| --- | --- | --- |
| /send | 120 | 2 |
| /status | 40 | 0 |
| /cancel | 15 | 1 |
| Total | 175 | 3 |

Each request returns a reference ID. See [Reference IDs](reference-ids.md) for the format.
