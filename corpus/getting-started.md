# Getting Started

Beacon is a small notification API. It requires Python 3.10 or newer.

Install the client and send a first message:

    pip install beacon-client
    beacon send --to alice --text "Hello"

The current release is 2.4.0. See the [API reference](api-reference.md) for the
full list of endpoints.
